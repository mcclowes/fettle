# Getting started

Fettle requires macOS 26 on Apple silicon.

```bash
brew install --cask mcclowes/fettle/fettle
```

Add a local Git repository from the project browser, or run `fettle <path>` after installing the command shim from **Help > Install `fettle` shim**.

To let a coding agent open its own work for review, choose **Help > Manage agent skills…**, then give the agent this prompt:

> Open your latest turn in Fettle for me to review.

The home screen combines local work, agent turns, clean branches ahead of their base, and open GitHub pull requests. Choose an item to open the review desk.
