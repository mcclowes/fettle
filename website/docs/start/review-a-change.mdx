# Review a change

Choose each changed file from the sidebar and read its unified or split diff. Mark each change block reviewed explicitly, or mark the whole file reviewed as a bulk action. Press `U` to jump to the next unreviewed change. Review marks follow unchanged content and become stale when that content changes.

Add comments to lines or files. Use review notes for feedback that applies to the whole change. Screenshots can carry numbered annotations that are flattened into the exported review packet.

Set the verdict to **Accepted** or **Needs work**, then export the packet for an agent. For a GitHub pull request, **Promote to GitHub** posts the new comments as a plain review comment. Fettle never approves, merges, or edits source files.
