# Commands

```text
fettle <path>…                       Open repositories
fettle turns [--json]                List turns for this terminal or worktree
fettle review [turn-id]              Open a turn review
fettle ai-review [pr-number] [--provider codex|claude]
                                     Review a pull request in a read-only Saggar agent terminal
fettle worktrees [--json] [--stale-after <days>]
                                     Inspect stale worktrees and suggested cleanup
fettle shim                          Print the shell shim that runs this binary
fettle skill                         Print where the bundled agent skill lives
fettle walkthrough lint <walkthrough.md> --request <request.json>
                                     Validate a walkthrough's syntax and evidence
fettle visual inspect [--json]       Detect screenshot-test systems
fettle visual status [--json]        Show normalized visual results
fettle visual run                    Run configured visual checks
fettle help
```

Inside a Saggar terminal, `SAGGAR_SESSION` scopes `turns` and `review` to that
session. Outside Saggar, they use the current Git worktree.

`ai-review` requires a Saggar terminal and a Git worktree. Give it a positive
pull request number, such as `fettle ai-review 42`, or omit the number to
review the current branch's pull request. It starts a new read-only reviewer
terminal, using Codex unless you choose `--provider claude`.

`worktrees` runs from a Git worktree. `--stale-after` takes a nonnegative
whole number of days; `0` is valid. It only prints cleanup commands; Fettle
never runs them.

Exit codes: 0 done, 1 refused or failed, 2 bad arguments, 3 unavailable,
such as a missing Git worktree or Saggar session.

Install the shim from **Help > Install the fettle shim…**.
