# Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| <kbd>⌘K</kbd> | Open the command palette |
| <kbd>⌘⇧P</kbd> | Promote the current review to GitHub |
| <kbd>⌘E</kbd> | Export the current review |
| <kbd>⌘R</kbd> | Refresh the review |

The command palette also lists changed files, review targets, repositories, and every available command.
