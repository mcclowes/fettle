# Support

For setup and usage questions, read the [documentation](https://fettle.marginalutility.dev/docs), then ask in [GitHub Discussions](https://github.com/mcclowes/fettle/discussions/categories/q-a).

Use the [bug report form](https://github.com/mcclowes/fettle/issues/new?template=bug.yml) for reproducible defects. Don't post source code, credentials, tokens, private repository names, or other sensitive information.
