# Fettle

Fettle is a native macOS app for reviewing code changes made by coding agents on your own machine.

[Visit the website](https://fettle.marginalutility.dev) or read the [documentation](https://fettle.marginalutility.dev/docs).

## Install

Fettle requires macOS 26 or newer on Apple silicon.

```bash
brew install --cask mcclowes/fettle/fettle
```
